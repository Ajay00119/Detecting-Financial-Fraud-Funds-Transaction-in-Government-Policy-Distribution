# Detecting Financial Fraud in Government Policy Distribution Using Blockchain

## 📌 Project Overview
This project is designed to detect fraudulent financial transactions in government fund distribution using blockchain technology.  
The system improves transparency, accountability, and security by recording every transaction in an immutable blockchain ledger.

Traditional fund monitoring systems rely on centralized databases, which are vulnerable to tampering, unauthorized modifications, and delayed fraud detection.  
This project solves that by integrating blockchain-based transaction verification and role-based monitoring.

---

## 🎯 Objective
- Prevent fraudulent fund transactions in government schemes  
- Maintain immutable transaction history  
- Detect unauthorized modifications in fund usage  
- Improve transparency in financial governance  

---

## 🧩 Modules
The system contains six main modules:

### 1. Admin Module
- User registration  
- Role assignment  
- Access control  

### 2. Finance Person Module
- Fund allocation  
- Blockchain transaction creation  

### 3. Contractor Module
- Expense submission  
- Project cost updates  

### 4. Engineer Module
- Expense verification  
- Report validation  

### 5. Supervisor Module
- Approval / rejection of verified reports  

### 6. Authority Module
- Fraud detection  
- Transaction analysis  
- Action against suspicious activity  

---

## 🔐 Features
- Blockchain-based secure transaction logging  
- Fraud detection through transaction comparison  
- Role-based authentication  
- Tamper-proof ledger  
- Real-time modification tracking
